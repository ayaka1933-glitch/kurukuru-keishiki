# くるくる景色診断

「くるくるくる展」に向けた、写真とコピーの体験プロトタイプ。

## 体験

- 一度に4枚の写真を表示し、好きな1枚を選ぶ。6回繰り返す。
- 時間制限なし。ひとつ前の問いに戻って選び直せる。
- キーボードの1〜4キーでも回答できる。
- 6回の選択に応じて4種類の診断結果を表示。
- 選んだ6枚を振り返り、カードを裏返して二つのコピーを読める。
- 感想を160文字以内で書き、このブラウザの保存領域に残す。
- 「残したことば」で保存したカードを読み返せる。

## 試作の前提

写真は提供された10枚のオリジナル。撮影機材は未確認なので、フィルムと一眼レフのペアという扱いはしていません。
10枚を異なる組み合わせで繰り返し提示します。各問いは「余韻 / 色 / 寄り道 / 余白」の各分類を1枚ずつ含み、分類の選択肢数を揃えています。
選ばれた回数が最大の分類を結果とし、同率なら同率分類の中で最後に選んだ分類を採用します。写真の好みを言葉にする遊びの分類です。
コピー、診断名、分類は試作用。`dist/app.js` の `photos`、`types`、`rounds` で編集できます。
感想は端末内のみに保存され、来場者間では共有しません。既存の保存データを引き継ぎます。

## ローカルで開く

このディレクトリで `python3 -m http.server 4318 --bind 127.0.0.1 --directory dist` を実行し、ブラウザで `http://127.0.0.1:4318/` を開きます。

## ファイル

- `dist/index.html`: 画面とテキストの構造
- `dist/style.css`: レイアウトと回転表現
- `dist/app.js`: 写真・コピー・4択の診断・感想保存
- `dist/assets/`: 提供写真10枚

2026-10-07: 表と裏の入口を追加。表は添付デジカメ4枚、裏は対応するフィルム4枚（夕暮れ1298・パンジー1284・庭1285・黄色1286）。同じ4枚を6つの問いで選び、モードごとに独立した結果を作る。最多の景色を結果にし、同点は直近の選択で決定。比較結果はページを開いている間だけ保持され、再読み込みで消える。ことばは従来通り端末内保存。

写真の読み取り：パンジーはデジカメの花びらの質感とフィルムの黄色のにじみ、夕暮れは橙の光と淡い残照、庭は手前のぼけと庭全体のにぎわい、道ばたは一輪の輪郭と周囲の生活風景。撮影距離・ピント・構図も違うため、媒体だけの効果を測る比較ではない。診断コピーはこの作品のための主観的な解釈。

確認：表・裏それぞれ4096通りの最多選択判定、異なるモードのIDと未完了回答の拒否、画像パス。ブラウザーで両モード6問、結果保持と比較、360px入口の横はみ出しなしを確認。
